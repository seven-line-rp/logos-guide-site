# Портреты преподавателей

Сюда кладём портреты в формате PNG. Имя файла — «Имя Фамилия.png», как в
списке преподавателей, только без отчества и имя впереди:

- `Александр Полянский.png`
- `Виктория Батмазова.png`
- `Екатерина Прохоренко.png`
- `Андрей Елисов.png`
- `Владимир Золотарев.png`

Лучше квадрат от 256×256 px, лицо по центру — на сайте портрет обрезается в
круг. Пока файла нет, на карточке показываются инициалы.
