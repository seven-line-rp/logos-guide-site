# Фотографии авторов

Загрузите сюда портреты авторов проекта (JPG, PNG или WebP). Имена файлов и регистр должны совпадать:

- `ksenia-davydova.jpg` — Давыдова Ксения
- `danila-lisovoy.jpg` — Лисовой Данила
- `timofey-bodyan.jpg` — Бодян Тимофей
- `artem-brekin.jpg` — Брекин Артем

Путь, используемый страницей «О проекте»: `/images/creators/<имя-файла>`. Если фотография ещё не добавлена, вместо неё отображаются инициалы автора. Рекомендуемый формат — вертикальный портрет 4:5, лицо по центру; сайт кадрирует изображение без изменения исходного файла.
