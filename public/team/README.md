# Фото команды

Сюда кладутся фотографии для страницы «О проекте». Имена файлов должны быть такими:

- `ksenia-davydova.jpg` — Давыдова Ксения
- `danila-lisovoy.jpg` — Лисовой Данила
- `timofey-bodyan.jpg` — Бодян Тимофей
- `artem-brekin.jpg` — Брекин Артем

Лучше вертикальное фото, примерно 800×1000. На сайте оно обрезается до 4:5, так что лицо
должно быть по центру. Если файла нет, вместо фото будут инициалы.

Перед тем как выкладывать, спросите у человека, можно ли.
