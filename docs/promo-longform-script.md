# Длинный промо-ролик ЛОГОС Путеводителя

**Черновик сценария на 2:15–2:30.** Основной диктор — тот же голос, что в текущем ролике (Piper `ru_RU-dmitri-medium`); его тембр и личность не меняем. Шутливая реплика Mr.Брекина остаётся за прежним рекламным голосом `denis`, без перезаписи. Текст рассчитан на живое, разговорное чтение примерно 135–145 слов в минуту, с паузами между главами.

Реклама — короткая вставка внутри фильма, не полноэкранная: отдельная карточка по центру, 50% кадра. Все цифры и обещания сверены с `docs/marketing.md`: 47 помещений, два этажа, 24 преподавателя и сотрудника; личное расписание вносит сам пользователь; после первого открытия путеводитель работает без интернета.

## Примерный хронометраж

- История и карта: 0:00–0:32
- Поиск, помещения и маршрут: 0:32–1:05
- Вставка Mr.Брекина: около 1:05, примерно 5 секунд
- Расписание, QR, преподаватели и офлайн-режим: 1:10–2:15
- Финальный логотип и музыкальная точка: до 2:25

Хронометраж уточняется после сборки дорожки прежним голосом: скрипт сборки выставит тайминги из фактической речи, а сцены нужно будет снимать по ним. Не растягивать старую 43-секундную дорожку и не дублировать фразы для достижения нужной длины.

## Голос и производство

- Основной голос: прежняя модель Piper `ru_RU-dmitri-medium`, без замены тембра и без изменения высоты.
- Реплика Mr.Брекина: существующий рекламный голос и существующий текст, не менять.
- Читать основной текст живо, дружелюбно и уверенно, с естественными паузами; не дикторским «объявлением» и не чрезмерно быстро.
- Для финальной озвучки нужны исходная модель Piper или новые записи этого же диктора по тексту выше. Пока исходника нет, в проекте следует оставить текущую короткую озвучку без изменений.
