# Картинка для превью ссылок (`public/og-image.png`)

Показывается, когда ссылку на сайт присылают во ВКонтакте, Telegram, WhatsApp и т. п.

- **Сюжет:** логотип «ЛОГОС Путеводитель» и схема коридора второго этажа с маршрутом
  от входа к кабинету физики 211.
- **Стиль:** плоская векторная схема в цветах сайта, без фото и градиентов.
- **Палитра:** фон `#f4f7fc`, текст `#13213a`, акцент и маршрут `#245ce5`, стены `#c9d5ea`,
  номера `#8d9ab0`. Логотип — исходник команды дизайна (`src/assets/logo-wordmark.js`).
- **Размер:** 1200×630, PNG.
- **Текст:** «Карта, маршруты и кабинеты колледжа», адрес logos-guide.ru.
- **Номера кабинетов** настоящие (202, 207, 209, 211, 214, 217, 222, 224 из `src/data.js`),
  но порядок на схеме условный: это иллюстрация, а не план этажа.

Как сделано: Recraft в сессии не был подключён, поэтому картинка нарисована вручную
как HTML + SVG (`og-image.html` рядом) и снята в Chromium на 1200×630:

```bash
npx playwright screenshot --viewport-size=1200,630 docs/assets/og-image.html public/og-image.png
```

Перед съёмкой дождитесь загрузки шрифта Onest (он берётся из `node_modules`).
