# Путеводитель по колледжу

Интерактивная карта двух этажей, поиск помещений, маршруты по коридорам и небольшие игры.

## Запуск

```bash
npm ci
npm run dev
```

Проверки: `npm test`, `npm run lint`, `npm run build`.

## ИИ-помощник LOGOS AI

**LOGOS AI** — искусственный интеллект сайта «Логос: Путеводитель». Разработчик — Лисовой Данила, студент 1-го курса группы П-1. Помощник отвечает по каталогу помещений, маршрутам и устройству сайта и не выдаёт себя за сторонний сервис: в системных правилах (`server/assistant-knowledge.mjs`) закреплено имя, автор и запрет раскрывать лежащую внизу модель. Тест `server/assistant-knowledge.test.mjs` следит, чтобы эти строки не потерялись.

**Как открыть:** кнопка «LOGOS AI» в шапке — помощник на всю страницу (работает и на телефоне); на компьютере есть и плавающее окно в правом нижнем углу.

**Диалоги хранятся в браузере** (`localStorage`, ключи `logos-ai-chats` и `logos-ai-active-chat`): список слева позволяет переключать, переименовывать и удалять чаты, а после перезагрузки страницы переписка остаётся на месте. Сервер диалоги не сохраняет — модели уходит только короткий хвост текущей беседы. Логика хранилища лежит в `src/assistant-chat-store.js` и покрыта тестами.

**Команда «Туторил»** — ключевое слово обучения. Если отправить его в чат, помощник запускает интерактивное обучение по сайту в стиле игровых подсказок: тёмный экран с прожектором вокруг элемента, пульсирующее кольцо, карточка с текстом и кнопки «Далее» / «Понятно». Шаги описаны в `src/tutorial.js` (у каждого — страница и селектор подсветки; если элемент не найден, шаг пропускается), показывает их `src/components/SiteTour.jsx`. Обучение можно пропустить, пройти заново или запустить кнопкой «Обучение по сайту» в списке диалогов; факт прохождения пишется в ключ `logos-tour-done`.

Ключ модели хранится только на сервере (`LOGOS_AI_API_KEY`, старое имя `DEEPSEEK_API_KEY` тоже читается). Подробная настройка и ограничения — в [`deploy/ai-assistant.md`](deploy/ai-assistant.md).

Для локальной разработки скопируйте `.env.example` в `.env`, укажите ключ и запустите `npm run dev`. Для production-варианта используйте `npm run build && npm start`. Обычная статическая публикация на Apache/reg.ru не запускает API — нужен Node.js-хостинг или серверный proxy.

## Публикация и перезагрузка страниц

Сайт — одностраничное приложение: на сервере лежит один `index.html`, а адреса `/map`, `/rooms`, `/route?from=118` разбирает React Router в браузере. Значит, хостинг обязан на любой неизвестный адрес отдавать `index.html`. Без этого перезагрузка страницы (F5) или переход по прямой ссылке заканчивается серверной ошибкой «404 — страница не найдена», хотя внутри сайта раздел открывается нормально.

В сборке это уже учтено:

- `public/.htaccess` — правила для Apache (общий хостинг reg.ru): существующие файлы отдаются как есть, отсутствующая статика честно даёт 404, всё остальное ведёт в `index.html`. Файл попадает в `dist` и начинает работать сразу после загрузки на хостинг.
- `public/404.html` + скрипт `spa-fallback:restore` в `index.html` — страховка, если `mod_rewrite` отключён: серверная страница 404 запоминает запрошенный адрес, а `index.html` возвращает его до загрузки приложения, и человек попадает на ту же страницу, на которой был.
- `deploy/nginx-spa.conf` — готовый server-блок для nginx (VPS или тариф только с nginx), ключевая строка `try_files $uri $uri/ /index.html;`.

Пошаговая инструкция для reg.ru, текст обращения в поддержку и способ проверить результат — в [`deploy/reg-ru.md`](deploy/reg-ru.md). Поведение хостинга локально повторяет `deploy/static-host-sim.mjs` (режимы `spa`, `error404`, `naive`), а тесты `src/spa-fallback.test.js` проверяют весь путь возврата адреса и запрещают переход на чужие домены через параметр `?__redirect=`.

## Карта и маршруты

Исходные планы: `map1lower.svg` и `map2lower.svg`. Координаты кликабельных помещений, дверей и проходов находятся в `src/map-geometry.js`.

**Рамки берутся из SVG, а не на глаз.** Значения в `planRoomBounds` — это осевые линии стен, которые нарисованы на плане (обводка фигуры в SVG шире её геометрии, поэтому обводка и рамка совпадают). Если план обновят, новые числа нужно снять с путей SVG; тест «each mapped room has a bounded hit area and a doorway» проверяет, что рамка не выходит за план, а «routes stay in circulation or in their own rooms…» — что маршрут не проходит сквозь чужие помещения. Если сдвинуть стену между коридором и кабинетами, поправьте и `circulation`: проход считается «внутри здания» только по этим полигонам.

**Медицинский блок под кабинетом 138** — медпункт (дверь в коридор) и кабинет врача (вход через медпункт). Проход через медпункт помечен в `roomAccess` полем `via` — это единственное исключение из правила «маршрут не идёт сквозь чужие помещения», и тесты читают его оттуда.

**Варианты маршрута.** На маршрутах между этажами страница маршрута строит четыре варианта — лифт и каждую из трёх лестниц (`buildRouteOptions` в `src/map-routing.js`) — и показывает их карточками, как в навигаторе: расстояние в метрах (масштаб плана снят с коридора: 24.5 единицы ≈ 2.5 м), время (походка + ожидание лифта или подъём), примерное число шагов и число шагов-указаний. Быстрый вариант отмечен плашкой «Быстрее» и выбирается по умолчанию; параметр `?mode=` в адресе понимает и общий режим (`lift`/`stairs`), и точный (`stairs-west`, `stairs-middle`, `stairs-north`).

**3D-камера и масштаб отрисовки.** Сдвиг плана в 3D-режиме считается в пикселях страницы, а фокусная точка — в единицах viewBox, поэтому `FloorMap` замеряет реальный масштаб отрисовки (`ResizeObserver`) и умножает на него сдвиг к центру. Без этого на широких панелях камера уезжала вниз: чем ниже точка на плане, тем сильнее расходились системы координат.

### Голосовые подсказки

Кнопка «Голос» на странице маршрута читает шаг вслух. Озвучка бывает двух видов:

- **Записанные голоса «Логос»** — женская и мужская записи. Фиксированные манёвры («Маршрут построен», «Идите по главному коридору…», «Поднимитесь на второй этаж») лежат в `public/voice/` и `public/voice/male/`; список фраз общий — `VOICE_PACK_PHRASES` в `src/voice-pack.js`. Первый и последний шаг тоже имеют общую записанную фразу, поэтому они не молчат на iPhone без русского системного голоса; конкретные названия кабинетов остаются на экране. Если mp3 не загрузился, полную фразу пробует прочитать системный синтезатор (при его отсутствии появляется сообщение рядом с кнопкой озвучки). Пакеты собственные: у 2ГИС нет публичной веб-библиотеки озвучки. Для новой записи добавьте mp3 и её ключ в `VOICE_PACK_PHRASES` и `voiceKey`/`voiceCue` шага.
- **Браузерный синтез речи** (`src/speech.js`) — запасной способ озвучки полного текста шага, когда запись недоступна. Выбирает русский системный голос (`ru-RU`), если он установлен; на некоторых телефонах его нет. Кнопка «Повторить» включает голос, если он был выключен. `prepareSpeechText` готовит номера кабинетов и аббревиатуры к чтению; тесты `src/speech.test.js` проверяют выбор голоса.

### Телефоны и iOS Safari

На экранах телефона в шапке остались быстрые действия «Карта», поиск и меню; язык, тема и кнопка ИИ-помощника доступны в меню. На странице карты план по умолчанию **крупный и прокручиваемый**, а не уменьшенная миниатюра: двигайте его одним пальцем, увеличивайте двумя пальцами или кнопками `+`/`−`. «Весь план» показывает общий вид; кнопка `1:1` сбрасывает дополнительный масштаб. На странице маршрута 2D включён по умолчанию на узких и низких экранах, планы также можно двигать пальцем; 3D остаётся доступен кнопкой. Декоративные hover-эффекты и их наблюдатели DOM не запускаются на сенсорных устройствах.

Safari разрешает Web Audio только после нажатия пользователя. `playVoicePack()` создаёт и возобновляет `AudioContext` **до первого `await`**, проверяет состояние `running` и не сообщает об успешном воспроизведении, если звук остался заблокирован. Для проверки нажмите «Прослушать» на странице маршрута; если тишина сохраняется, проверьте громкость и беззвучный режим устройства. Автоматической озвучки при открытии страницы нет — это ограничение браузера. Тесты `src/voice-mobile.test.js` покрывают разблокировку и заблокированный контекст, `src/map-zoom.test.js` — масштаб карты при её увеличенной базовой ширине.

### Поиск кабинета и последовательный 3D-показ этажей

Вместо длинных выпадающих списков поля «Откуда» и «Куда» на странице маршрута — живой поиск (`src/components/RoomSearchSelect.jsx`): фильтрация по названию, номеру (в том числе по цифрам составных номеров вроде «147, 141…»), псевдонимам и категории; работает с клавиатуры (стрелки, Enter, Escape) и совместим с экранными дикторами (ARIA combobox).

На широком экране в 3D-режиме камера показывает этажи **по очереди**: сначала план этажа старта, а план второго этажа «включается» в момент шага перехода (оба плана смонтированы и переключаются плавно, камера при этом приподнимается из плоского вида). В виде «Сверху» (2D) оба плана остаются рядом, как раньше.

### Точка-поводырь и пройденные шаги

Маршрут на плане делится на пройденную часть (бледная линия) и оставшуюся (яркая со стрелками); оранжевая точка стоит на вершине текущего шага и переезжает при листании. Вершины описаны в `guides` у каждого участка маршрута (`src/map-routing.js`) — это готовые подсказки «поверните в коридор западного крыла», «идите по главному коридору в сторону холла» с привязкой к индексу точки. Если маршрут станет сложнее, добавляйте новые ориентиры там же, а не в разметке страницы. Алгоритм строит путь вдоль главного коридора и западного крыла; для перехода между этажами выбирает лифт или ближайшую из трёх лестниц (`src/map-routing.js`). Если план меняется, обновите SVG, геометрию и тесты вместе. Маршрут не учитывает временно закрытые помещения и не гарантирует доступность проходов.

Ручная отметка ставится **в любой точке помещения или коридора**, сохраняется только в браузере пользователя и может стать началом маршрута. Её можно удалить на карте.

**GPS не определяет этаж и не привязан к схеме автоматически.** Чтобы появилась приблизительная метка, на выбранном этаже включите GPS и отметьте две известные точки, находясь в них. Первая точка показывается как неподвижный ориентир, после второй рассчитываются масштаб и поворот плана. Координаты этих двух точек сохраняются только в локальном хранилище браузера; другие полученные GPS-координаты никуда не передаются. Внутри здания погрешность может превышать размеры кабинета: при сомнении используйте ручную отметку. Функция требует HTTPS и разрешения на геолокацию.

### Языки интерфейса и поиск

- Переключатель RU / EN находится в меню и хранит выбор в `site-language`; язык страницы (`html.lang`) и заголовок вкладки обновляются без перезагрузки.
- Английский каталог: `src/locales/en.js`. `src/i18n.js` переводит только представление, сохраняя исходные данные маршрутов и русскую записанную озвучку.
- Vite-плагин `scripts/localize-jsx.js` добавляет перевод к тексту JSX, динамическим подписям и доступным атрибутам. Значения полей, идентификаторы, обработчики и исходные данные не переводятся.
- Поиск понимает русские и английские названия независимо от выбранного языка.
- Одна клавиша **K** открывает поиск (также **Л** на той же клавише русской раскладки и **К**). В полях ввода, при IME-композиции и удержании клавиши хоткей не срабатывает. Ctrl/⌘+K вне полей ввода также поддерживается.
