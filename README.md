# Путеводитель по колледжу

Интерактивный русскоязычный навигатор по двум этажам колледжа. Включает схему помещений, справочник кабинетов, построение простого маршрута и мини-игры для знакомства с планом.

## Разделы

- `/` — быстрый поиск и популярные места
- `/map` — интерактивная карта первого и второго этажей
- `/rooms` — поиск помещений по названию, номеру, этажу и типу
- `/route` — текстовый маршрут с выбором лифта или лестницы
- `/games` — квиз по этажам и игра «Найди на карте»
- `/services` — столовая, библиотека, актовый зал, мастерские и другие пространства
- `/about` — инструкция и оговорки по доступности схемы

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

Стек: React, React Router, Vite. План этажей — SVG. Фотографии команды добавляются в `public/images/creators/`; точные имена файлов и формат описаны в `public/images/creators/README.md`.

Для отметки GPS на плане сначала разрешите геолокацию, затем нажмите «Привязать GPS» и коснитесь своего места на схеме. Одноразовая привязка нужна потому, что план здания сам по себе не содержит географических координат; внутри помещений GPS также может ошибаться. Метку «Вы здесь» можно поставить вручную касанием любой точки плана.
