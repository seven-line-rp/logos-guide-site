# ЛОГОС: путеводитель по колледжу

Сайт с картой нашего корпуса. Можно найти кабинет по номеру или названию,
посмотреть его на плане этажа и построить маршрут от входа или от другого
кабинета. Делали как учебный проект, состав команды есть на странице «О проекте».

Сайт: https://logos-guide.ru

## Что есть на сайте

- карта двух этажей (`/map`), можно приближать и выбирать кабинеты
- поиск по кабинетам и преподавателям, в том числе голосом
- маршрут по коридорам (`/route`), между этажами по лестнице или на лифте, с озвучкой
- справочник кабинетов (`/rooms`) и список преподавателей (`/teachers`)
- звонки на сегодня на главной и напоминания за 5 минут до пары
- QR-таблички «Вы здесь» для дверей (`/here`)
- игры, чтобы запомнить план (`/games`)
- чат с нейросетью (`/ai`), работает через DeepSeek
- push-уведомления о парах, событиях и новых версиях (`/notifications`, колокольчик в шапке)
- темы: светлая, тёмная и розовая «Пикми» (тёмную и «Пикми» можно выключить для
  всех в панели `/admin/settings`); английский язык
- «Где я» на карте и ведение по маршруту: GPS, а где он слабый — счёт шагов
  датчиком телефона и (если установлены) Bluetooth-маячки
- панель `/admin`: статистика, объявления, уведомления, обращения, темы и маячки

## Как запустить

Нужен Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Сайт откроется на http://localhost:5173.

Другие команды:

```bash
npm test        # тесты
npm run lint    # проверка кода
npm run build   # сборка в папку dist
```

## На чём сделано

React 19, React Router и Vite. Иконки из `lucide-react`, формулы в чате
рисует KaTeX. Серверная часть (чат, объявления, статистика, уведомления) написана на PHP,
потому что на хостинге reg.ru есть только PHP. Базы данных нет, всё хранится в
JSON-файлах.

## Где что лежит

```
src/
  pages/        страницы сайта, по файлу на раздел
  components/   то, что используется на нескольких страницах (шапка, карта, поиск...)
  admin/        панель /admin
  locales/      английский перевод
  data.js       все кабинеты: номер, этаж, координаты на плане
  map-routing.js  поиск пути по коридорам
  search.js     поиск кабинетов и преподавателей
  seo.js        заголовки и описания страниц для поиска и превью ссылок
  *.test.js     тесты (запускаются через node --test)
public/
  api/          PHP-скрипты
  rooms/        фото кабинетов
  voice/        записанные голосовые подсказки
deploy/         инструкции по выкладке и настройке сервера
docs/           позиционирование (marketing.md), промо-ролик (promo.md), описания картинок (assets/)
promo-voice/    свой голос для промо-ролика: текст фраз и куда класть записи
```

Планы этажей нарисованы в `map1lower.svg` и `map2lower.svg`. Стены, двери и
кабинеты поверх них берутся из `src/data.js` и `src/map-art.js`. Если
кабинет переехал или поменялся номер, править надо в `src/data.js`.

Маршрут строится так: от двери кабинета до коридора, по коридору до нужной
двери. Коридоров на этаже по сути два, главный и западное крыло, они
сходятся в одной точке. Если надо на другой этаж, считаются все варианты
(лифт и три лестницы) и первым показывается самый быстрый. Код в
`src/map-routing.js`, тесты в `src/map-routing.test.js`.

## Выкладка

Сайт лежит на обычном хостинге reg.ru. Собираем `npm run build` и заливаем
содержимое `dist` в `public_html`. Подробно, включая настройку чата и
оповещений, написано в папке `deploy/`:

- `deploy/reg-ru.md` — выкладка, и почему `/map` может отдавать 404 после F5
- `deploy/ai-agent.md` — чат с нейросетью
- `deploy/alerts.md` — оповещения в Telegram, если сайт упал
- `deploy/notices.md` — объявления на карте («лестница закрыта» и т.п.)
- `deploy/reports.md` — сообщения об ошибках на карте
- `deploy/stats.md` — счётчик посещений
- `deploy/push.md` — push-уведомления, крон для звонков
- `deploy/settings.md` — темы для всех и Bluetooth-маячки

## Cookie и данные

Регистрации нет, сторонней аналитики тоже. Настройки (тема, избранное,
недавние маршруты) хранятся в `localStorage` браузера. Если добавляете новый ключ в
`localStorage`, впишите его в `src/pages/privacy-items.js`, иначе упадёт тест.
