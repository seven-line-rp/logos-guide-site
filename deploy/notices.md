# Объявления на карте

Объявления («ремонт, проход закрыт», «концерт в актовом зале») можно вести
двумя способами.

## Способ 1. Страница `/admin` (удобнее)

Панель `https://сайт/admin` не видна в меню; объявления — в разделе «Объявления» (`/admin/notices`). Сотрудник вводит ключ,
добавляет объявление (тип, помещение, заголовок, даты) и нажимает «Сохранить
на сайте». Список сохраняется в файл `logos-notices.json` **рядом с папкой
сайта** (на уровень выше `public_html`), поэтому переживает перезаливку `dist`.

Чтобы включить, задайте ключ в том же конфиге, что и у ИИ-агента
(`logos-ai-config.php` рядом с `public_html`, см. `deploy/ai-agent.md`):

```php
return [
    // …
    'notices_key' => 'длинная-случайная-строка',
];
```

Без ключа страница скажет «Правка объявлений не настроена». После десяти
неверных ключей с одного адреса вход закрывается на час. Если PHP не может
писать рядом с `public_html`, страница предупредит при входе.

Сайт читает объявления через `api/notices.php`: сначала `logos-notices.json`,
а если его нет — `notices.json` из корня сайта (способ 2). ЛОГОС AI тоже
берёт их оттуда.

## Способ 2. Файл `notices.json`

Объявления лежат в файле `notices.json` в корне сайта на хостинге, рядом с
`index.html`. Пересобирать сайт не нужно: откройте файл в файловом менеджере
reg.ru, поправьте и сохраните. Посетители увидят изменения при следующем
открытии страницы. Если со страницы `/admin` уже что-то сохраняли, этот файл
не используется — удалите `logos-notices.json`, чтобы вернуться к нему.

## Что видно на сайте

- значок над помещением на 2D- и 3D-карте и список объявлений этажа под картой;
- предупреждение в карточке кабинета и на странице маршрута;
- закрытые лестницы и лифт маршрут обходит сам, выбирая другой подъём;
- ЛОГОС AI знает действующие объявления и предупреждает о них.

## Формат

```json
[
  {
    "type": "closed",
    "roomId": "stairs-west-1",
    "title": "Ремонт лестницы",
    "text": "Западная лестница закрыта, поднимайтесь по центральной",
    "from": "2026-10-20T08:00:00+03:00",
    "to": "2026-10-24T18:00:00+03:00"
  },
  {
    "type": "event",
    "roomId": "auditorium-104",
    "title": "Концерт в 15:00"
  }
]
```

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `type` | да | `closed` — закрыто, `event` — событие, `info` — важная информация |
| `roomId` | да | id помещения из `src/data.js`, например `library-214`, `stairs-middle-2`, `lift-1` |
| `title` | да | Короткий заголовок, до 40 символов |
| `text` | нет | Подробности одной фразой |
| `from`, `to` | нет | Когда показывать. Без дат объявление висит, пока его не удалят |

Если в файле ошибка (лишняя запятая, неизвестный `roomId`), сайт просто не
покажет неверное объявление. Проверить JSON можно на любом онлайн-валидаторе.
Пустой список — `[]`.
