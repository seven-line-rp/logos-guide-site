# Объявления на карте

Например «лестница на ремонте» или «концерт в актовом зале». Объявление
показывается значком на карте, в карточке кабинета и на странице маршрута.
Если закрыта лестница или лифт, маршрут сам пойдёт по другой.

Добавлять можно двумя способами.

## Через /admin

Панель `https://сайт/admin/notices` (в меню её нет). Нужно ввести ключ,
заполнить объявление и нажать «Сохранить на сайте». Всё сохраняется в
`logos-notices.json` на уровень выше `public_html`, поэтому при новой выкладке
сайта объявления не пропадут.

Ключ задаётся в файле `logos-ai-config.php` на уровень выше `public_html`:

```php
return [
    // ...
    'notices_key' => 'длинная-случайная-строка',
];
```

После 10 неправильных ключей с одного адреса вход блокируется на час.

## Через файл notices.json

Файл лежит в корне сайта рядом с `index.html`, его можно поправить прямо в
файловом менеджере reg.ru, пересобирать ничего не надо. Но если уже есть
`logos-notices.json` из админки, читается он, а `notices.json` игнорируется.

Формат:

```json
[
  {
    "type": "closed",
    "roomId": "stairs-west-1",
    "title": "Ремонт лестницы",
    "text": "Западная лестница закрыта, поднимайтесь по центральной",
    "from": "2026-10-20T08:00:00+03:00",
    "to": "2026-10-24T18:00:00+03:00"
  },
  { "type": "event", "roomId": "auditorium-104", "title": "Концерт в 15:00" }
]
```

- `type` — `closed` (закрыто), `event` (событие) или `info`
- `roomId` — id из `src/data.js`, например `library-214`, `stairs-middle-2`, `lift-1`
- `title` — заголовок, лучше до 40 символов
- `text` — необязательно, подробности
- `from`, `to` — необязательно, с какого и до какого времени показывать

Если в объявлении ошибка (неизвестный `roomId`, лишняя запятая), оно просто не
покажется. Пустой список — `[]`.
