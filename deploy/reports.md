# Обращения с сайта и неточности на карте

Два входа в один файл: кнопка «Сообщить о неточности» в панели помещения и общая страница `/feedback` («Сообщить о проблеме» в меню и подвале: баг, ошибка ИИ, идея, вопрос). У обращений с `/feedback` в строке JSON есть `"scope":"site"`, `kind` равен `bug`, `ai`, `idea` или `question`, `room` пустой, и добавлены `contact` (необязательный контакт) и `agent` (браузер). Лимиты и чтение те же. Комментарий — до 1200 знаков.

В панели помещения на карте есть кнопка «Сообщить о неточности». Сообщение
уходит на `public/api/report.php` и сохраняется на сервере — без базы данных
и внешних сервисов. Нужен обычный PHP 7.4+ (на reg.ru есть).

## Где лежат сообщения

Файл `logos-reports/reports.jsonl` **рядом с папкой сайта** (на уровень выше
`public_html`), по одной строке JSON на сообщение:

```json
{"at":"2026-10-20T10:15:00+03:00","room":"class-118","kind":"closed","text":"Дверь заперта","page":"/map?floor=1&room=class-118","visitor":"1b318fe01a2f9bcf"}
```

- `room` — id помещения из `src/data.js`;
- `kind` — что не так: `wrong-place` (не там на плане), `closed` (закрыто),
  `moved` (переехало), `wrong-name` (другое название или номер), `other`;
- `visitor` — обезличенный хеш IP: по нему видно, что сообщения от одного
  человека, но не сам адрес.

Если писать выше `public_html` хостинг не разрешает, файл окажется во
временной папке PHP (`sys_get_temp_dir()/logos-reports-…`). Проверить, что
запись работает: `https://сайт/api/report.php?health` → `{"ok":true}`.

## Как читать

1. Через файловый менеджер хостинга — открыть `logos-reports/reports.jsonl`.
2. Через браузер — задать ключ в том же конфиге, что и у ИИ-агента
   (`logos-ai-config.php` рядом с `public_html`, см. `deploy/ai-agent.md`):

   ```php
   return [
       // …настройки ИИ-агента…
       'reports_key' => 'длинная-случайная-строка',
       // По желанию: копия каждого сообщения на почту (функция mail() хостинга).
       'reports_email' => 'team@example.com',
   ];
   ```

   и открыть `https://сайт/api/report.php?list&key=длинная-случайная-строка` —
   последние 200 сообщений, новые сверху.

## Ограничения

Не больше 5 сообщений в час с одного адреса и 200 в сутки на весь сайт;
комментарий — до 1200 знаков. Запросы с чужих сайтов отклоняются.

## «Искали и не нашли»

Если поиск на сайте ничего не нашёл, страница отправляет на
`api/search-miss.php` только текст запроса. Сервер ведёт счётчики в
`logos-reports/search-misses.json` (IP не сохраняется; запросы, похожие на
телефон, почту или ссылку, отбрасываются). Список самых частых запросов —
по тому же ключу `reports_key`:

`https://сайт/api/search-miss.php?list&key=длинная-случайная-строка`

Что с ним делать: дописать недостающие слова в `aliases` нужного помещения в
`src/data.js` («ксерокс» → библиотека) или добавить место на план.
