# Сообщения об ошибках

Пользователь может написать нам двумя способами: кнопкой «Сообщить о
неточности» в карточке кабинета на карте или через страницу `/feedback`
(баг, ошибка чата, идея, вопрос). Всё попадает в `public/api/report.php` и
пишется в один файл. Базы данных нет.

## Где смотреть

Удобнее всего в панели: раздел «Обращения» (`/admin/reports`), вход по ключу
`notices_key`. Там сообщения можно отметить решёнными или удалить. Решённое
получает поле `done` с датой.

Файл `logos-reports/reports.jsonl` на уровень выше `public_html`. Одна строка —
одно сообщение:

```json
{"at":"2026-10-20T10:15:00+03:00","room":"class-118","kind":"closed","text":"Дверь заперта","page":"/map?floor=1&room=class-118","visitor":"1b318fe01a2f9bcf"}
```

`kind` для карты: `wrong-place`, `closed`, `moved`, `wrong-name` или `other`.
У сообщений с `/feedback` стоит `"scope":"site"`, `kind` один из `bug`, `ai`,
`idea`, `question`, и могут быть `contact` и `agent` (браузер). `visitor` — это
хеш от IP, сам IP не сохраняется.

Если хостинг не даёт писать выше `public_html`, файл окажется во временной
папке PHP. Проверить, что всё работает: `https://сайт/api/report.php?health`
должен ответить `{"ok":true}`.

Читать можно через файловый менеджер, а можно через браузер. Для этого в
`logos-ai-config.php` добавить ключ (и, если хочется, почту для копий):

```php
'reports_key' => 'длинная-случайная-строка',
'reports_email' => 'team@example.com',
```

и открыть `https://сайт/api/report.php?list&key=...` — будут последние 200
сообщений.

Ограничения: 5 сообщений в час с одного адреса, 200 в сутки всего, текст до
1200 символов.

## Что искали и не нашли

Если поиск ничего не нашёл, сайт отправляет текст запроса в
`api/search-miss.php`. Там считается, что ищут чаще всего (без IP, а запросы,
похожие на телефон, почту или ссылку, выкидываются). Посмотреть:
`https://сайт/api/search-miss.php?list&key=<reports_key>`.

Это удобно, чтобы дописывать синонимы: если часто ищут «ксерокс», добавляем
это слово в `aliases` библиотеки в `src/data.js`.
