# ИИ-агент (DeepSeek) на обычном хостинге — без VDS и Node.js

Страница `/ai` («ИИ-Агент · ТЕСТ» в шапке) — чат с нейросетью DeepSeek. Он
знает план корпуса и разделы путеводителя, а про колледж читает
колледжлогос.рф.

## Как это устроено

```
браузер  ──POST /api/ai-chat.php──▶  PHP на хостинге reg.ru  ──▶  api.deepseek.com
                                       │  ключ API хранится здесь
                                       ├─ api/ai-knowledge.txt — кабинеты и разделы (из src/data.js при сборке)
                                       └─ колледжлогос.рф — PHP скачивает сам, кэш 12 ч
```

- **Почему PHP, а не ключ прямо в JavaScript.** Всё, что лежит в `dist`, может
  скачать любой посетитель, а ещё `dist` выкладывается zip-архивом в публичный
  релиз на GitHub. Ключ из JS украдут за минуту и потратят баланс. PHP есть на
  любом тарифе reg.ru и запускается сам, ничего устанавливать не нужно.
- `public/api/ai-chat.php` — прокси. Он проверяет запрос, добавляет системную
  подсказку и отправляет её в DeepSeek. Ещё он следит за бюджетом и лимитами
  (см. «Бюджет» ниже) и принимает запросы только со своего домена.
- `api/ai-knowledge.txt` собирается из `src/ai-knowledge.js` при `npm run build`.
  Если поменять кабинеты в `src/data.js`, агент узнает о них после следующей сборки.
- **Сайт колледжа.** Сначала прокси читает страницы и последние новости через
  WordPress REST API (`/wp-json/wp/v2/...`). Если API закрыт, он берёт главную
  и до 15 страниц, на которые она ссылается. Затем убирает меню и подвал,
  складывает текст (до 30 000 символов) во временную папку и обновляет его раз
  в 12 часов. Если сайт колледжа не отвечает, агент работает на старом кэше
  или только на базе знаний.
- Сервер переписку не хранит. Чаты сохраняются только в браузере посетителя
  (`localStorage`, ключ `logos-ai-chats`), картинки перед отправкой сжимаются
  до 1024 px.
- **Картинки и «Подумать глубже».** Прокси сначала пробует отправить картинки
  (формат `image_url`, как у OpenAI) и параметр `thinking`. Если DeepSeek
  отвечает 400/422, потому что модель не видит картинки или не знает
  параметр, прокси сам повторяет запрос попроще. Тогда агент честно говорит,
  что картинку не видит, и просит описать её словами, а на странице появляется
  подсказка. Ход мыслей из режима рассуждений (`reasoning_content`) можно
  раскрыть под ответом.
- **Мат** маскируется в браузере (`maskProfanity` в `src/ai-chat.js`):
  в DeepSeek и в историю чата уходит «б***», а вместе с запросом — пометка
  `rude`. В ответ агент сам входит в театральный «враждебный режим»
  (раздел «Если с тобой грубят» в подсказке `ai-chat.php`), а в чате
  проигрывается «отправка куратору» с отсчётом на извинения. Извинился — прощён.

## Установка на reg.ru

1. **Ключ.** Если ключ где-то засветился (в чате, в коммите, на скриншоте),
   сначала выпустите новый на [platform.deepseek.com](https://platform.deepseek.com/api_keys),
   а старый удалите.
2. **Конфиг с ключом.** Скопируйте `deploy/logos-ai-config.example.php` в файл
   `logos-ai-config.php`, впишите ключ и загрузите его **на уровень выше корня сайта**:

   ```
   /var/www/uXXXXXXX/data/www/logos-ai-config.php        ← конфиг
   /var/www/uXXXXXXX/data/www/logos-guide.ru/index.html  ← корень сайта (содержимое dist)
   ```

   Там файл не доступен из интернета и не пропадёт при следующей загрузке `dist`.
   Если в эту папку загрузить нельзя, положите конфиг как `api/ai-config.php`
   внутрь сайта. Снаружи его закрывает `api/.htaccess`, но тогда его придётся
   загружать заново после каждого обновления.
3. **Сборка и загрузка.** Выполните `npm run build` и загрузите содержимое `dist`, как обычно
   (см. `deploy/reg-ru.md`). Проверьте, что на хостинге появилась папка `api/` с
   `ai-chat.php`, `ai-knowledge.txt` и `.htaccess`.
4. **Версия PHP.** В панели reg.ru → «Сайты» → ваш домен → версия PHP: нужна
   7.4 или новее (лучше 8.x) с расширением `curl` — на reg.ru оно включено по умолчанию.
5. **Проверка.** Откройте `https://logos-guide.ru/api/ai-chat.php?health=1` — должно быть
   `{"ok":true,"model":"deepseek-v4-flash","vision":true,"knowledge":true,"curl":true}`.
   `ok:false` — конфиг с ключом не найден. Затем откройте `/ai` и задайте вопрос.

## Настройки

Все параметры — в `logos-ai-config.php` (значения по умолчанию в начале `ai-chat.php`):

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `api_key` | — | Ключ DeepSeek (можно задать и переменной окружения `DEEPSEEK_API_KEY`) |
| `model` | `deepseek-v4-flash` | Модель; `deepseek-v4-pro` умнее, но дороже |
| `monthly_budget_usd` | `2.0` | Сколько долларов можно потратить за месяц |
| `price_input_miss` / `price_input_hit` / `price_output` | `0.30` / `0.006` / `1.20` | Цены DeepSeek за 1 млн токенов (вход без кэша / из кэша / ответ) |
| `per_ip_daily` | `15` | Вопросов в день с одного IP |
| `deep_per_ip_daily` | `4` | Из них в режиме «Подумать глубже» |
| `per_ip_limit` | `8` | Вопросов с одного IP за 10 минут |
| `daily_limit` | `400` | Жёсткий потолок вопросов на весь сайт за сутки |
| `max_tokens` | `1400` | Максимальная длина ответа |
| `deep_max_tokens` | `3000` | Длина ответа в режиме «Подумать глубже» (с рассуждениями) |
| `vision` | `true` | Отправлять ли модели приложенные картинки |
| `vision_model` | — | Отдельная модель для запросов с картинками, если основная их не видит |
| `college_cache_hours` | `12` | Как часто перечитывать колледжлогос.рф |
| `college_max_chars` | `15000` | Сколько текста сайта колледжа давать модели |

## Бюджет: $2 в месяц на ~200 человек

Остаток месячного бюджета делится на оставшиеся дни месяца (включая сегодня):
1-го числа это $2 ÷ 30 ≈ **$0,066 в день**, а если вчера потратили меньше,
сегодня можно больше. После каждого
ответа прокси берёт из ответа DeepSeek поле `usage` (токены из кэша, без кэша
и ответа), считает стоимость по ценам из настроек и складывает её в файл
лимитов. Когда дневная доля потрачена, агент до полуночи по Москве отвечает
«Лимит на сегодня исчерпан». Неиспользованное за день переходит на следующие
дни, но за месяц больше бюджета всё равно не уйдёт: расход месяца
(`month_spent`) хранится в том же файле лимитов и обнуляется 1-го числа. Если DeepSeek ответил
ошибкой, вопрос человеку не засчитывается.

Цены взяты по дорогому «пиковому» тарифу Flash ($0,30 / $1,20 за 1 млн
токенов), так что расчёт с запасом. Сколько стоит один ответ:

- системная подсказка (кабинеты и текст сайта колледжа) — около 12 тыс.
  токенов. Она одинакова у всех запросов, и DeepSeek берёт её из кэша по
  $0,006 за 1 млн, то есть меньше $0,0001;
- история разговора и вопрос — 1–2 тыс. токенов без кэша, около $0,0005;
- ответ — до 1400 токенов, обычно 300–600, около $0,0005–0,0017.

Итого **≈ $0,001–0,002 за обычный ответ** и около $0,003–0,006 за «Подумать
глубже». В месяц помещается около 1 200–1 800 ответов. Личный лимит —
15 вопросов в день (из них 4 «глубже»), чтобы один человек не потратил дневной
бюджет за всех.

## Что агент умеет обсуждать

Агент — универсальный ИИ с шуточной манерой общения и знаниями о колледже:
он отвечает на любые вопросы, почти ничего не отклоняет (твёрдые границы —
только серьёзный вред и сексуальный контент), без нотаций и лишних
дисклеймеров, решает задачи и пишет код — блоки кода показываются с кнопкой «Копировать».
Длина ответа зависит от вопроса. Факты о колледже он по-прежнему не
выдумывает. Сообщения с матом не блокируются: грубые слова маскируются («б***») ещё в
браузере, а агент отвечает в шуточном враждебном режиме.

Сколько потрачено сегодня, видно в `…/api/ai-chat.php?health=1`
(`today.spent_usd`, `today.month_spent_usd` и `daily_budget_usd`). Пополнили счёт или хотите щедрее —
поменяйте `monthly_budget_usd` в `logos-ai-config.php`.

## Ошибки

| На странице | Причина |
| --- | --- |
| «ИИ-агент ещё не загружен на этот сервер» | Нет `api/ai-chat.php` (не загрузили `dist/api`) или хостинг не выполняет PHP |
| «ИИ-агент ещё не настроен на сервере» | Не найден конфиг с ключом или выключен `curl` |
| «Сервер ИИ отклонил ключ API» | Неверный или удалённый ключ |
| «На счёте DeepSeek закончились средства» | Пополните баланс в кабинете DeepSeek |
| «Слишком много сообщений подряд» | Сработал лимит; подождите или увеличьте `per_ip_limit` |
| «Вы задали все 15 вопросов на сегодня» | Личный дневной лимит, `per_ip_daily` |
| «Лимит ИИ-агента на сегодня исчерпан» | Потрачена дневная доля бюджета (`monthly_budget_usd` ÷ дней в месяце) |

Подробности ошибок DeepSeek пишутся в журнал ошибок PHP (панель reg.ru → «Логи»).

## Локальная разработка

Vite не выполняет PHP, поэтому чат в `npm run dev` проксируется на встроенный
сервер PHP:

```bash
npm run build
cp deploy/logos-ai-config.example.php dist/api/ai-config.php   # впишите ключ
php -S localhost:8787 -t dist      # в отдельном терминале
npm run dev                        # /api/* уйдёт на localhost:8787
```

`node server.mjs` отдаёт только статику, и чат в нём не работает. Если сайт
когда-нибудь переедет на Node или VPS, прокси можно оставить на PHP или
перенести ту же логику в обработчик `/api/ai-chat.php`.
