# Чат с нейросетью (/ai)

Чат работает через API DeepSeek. Он знает кабинеты и разделы сайта, а про
колледж читает информацию с колледжлогос.рф.

## Как устроено

```
браузер ──POST /api/ai-chat.php──▶ PHP на reg.ru ──▶ api.deepseek.com
                                    │ здесь хранится ключ API
                                    ├ api/ai-knowledge.txt (кабинеты, собирается из src/data.js)
                                    └ текст с колледжлогос.рф (кэш на 12 часов)
```

Ключ нельзя класть в JavaScript: всё из `dist` может скачать кто угодно, и ключ
быстро украдут. Поэтому запросы идут через `public/api/ai-chat.php`. Он
добавляет к вопросу системную подсказку, отправляет в DeepSeek, считает
расходы и принимает запросы только с нашего сайта.

`api/ai-knowledge.txt` создаётся при `npm run build` из `src/ai-knowledge.js`.
Если поменять кабинеты в `src/data.js`, чат узнает об этом после следующей сборки.

Сайт колледжа скрипт читает через WordPress API, а если он закрыт, берёт главную
и до 15 страниц по ссылкам с неё. Если сайт колледжа не открывается, используется
старый кэш.

Переписку сервер не хранит. Чаты лежат в `localStorage` браузера (ключ
`logos-ai-chats`). Картинки перед отправкой уменьшаются до 1024 px.

Что ещё есть в чате:

- кнопка «Подумать глубже» — режим рассуждений DeepSeek, ход мыслей можно раскрыть под ответом
- режим «Зачёт» (`/ai?mode=study`) — короткая теория и в конце 3–5 заданий с проверкой
  прямо на странице (`src/ai-quiz.js`)
- формулы через KaTeX, графики (`src/components/ai-chart.js`), блоки кода с кнопкой «Копировать»
- под ответом бывают кнопки с вопросами-продолжениями
- мат заменяется звёздочками ещё в браузере (`maskProfanity` в `src/ai-chat.js`)

Если модель не умеет картинки или не знает параметр `thinking`, скрипт сам
повторяет запрос без них.

## Установка

1. Получить ключ на [platform.deepseek.com](https://platform.deepseek.com/api_keys).
   Если ключ где-то засветился, удалить его и сделать новый.
2. Скопировать `deploy/logos-ai-config.example.php` в `logos-ai-config.php`,
   вписать ключ и положить на уровень выше папки сайта:

   ```
   /var/www/uXXXXXXX/data/www/logos-ai-config.php        ← конфиг
   /var/www/uXXXXXXX/data/www/logos-guide.ru/index.html  ← сайт
   ```

   Так конфиг не открыть из интернета, и он не сотрётся при новой выкладке.
   Если туда класть нельзя, можно положить как `api/ai-config.php` внутрь сайта
   (его закрывает `api/.htaccess`), но тогда его придётся заливать каждый раз.
3. `npm run build` и залить `dist` (см. `reg-ru.md`). В папке `api/` на хостинге
   должны быть `ai-chat.php`, `ai-guard.php`, `alert.php`, `client-error.php`,
   `ai-knowledge.txt` и `.htaccess`.
4. В панели reg.ru выбрать PHP 7.4 или новее (лучше 8), нужен `curl`.
5. Открыть `https://logos-guide.ru/api/ai-chat.php?health`. Должно быть
   `{"ok":true}`. Если `ok:false`, конфиг не найден.

## Настройки

Всё в `logos-ai-config.php`, значения по умолчанию в начале `ai-chat.php`.

| Параметр | По умолчанию | Что это |
| --- | --- | --- |
| `api_key` | — | ключ DeepSeek (или переменная окружения `DEEPSEEK_API_KEY`) |
| `model` | `deepseek-v4-flash` | модель, `deepseek-v4-pro` умнее, но дороже |
| `monthly_budget_usd` | `2.0` | сколько долларов можно потратить в месяц |
| `price_input_miss` / `price_input_hit` / `price_output` | `0.30` / `0.006` / `1.20` | цены за 1 млн токенов |
| `per_ip_daily` | `15` | вопросов в день с одного IP |
| `deep_per_ip_daily` | `4` | из них «Подумать глубже» |
| `per_ip_limit` | `8` | вопросов с одного IP за 10 минут |
| `daily_limit` | `400` | всего вопросов на сайт за сутки |
| `max_tokens` | `2200` | максимальная длина ответа |
| `deep_max_tokens` | `3000` | то же для «Подумать глубже» |
| `vision` | `true` | отправлять ли картинки |
| `vision_model` | — | отдельная модель для картинок |
| `college_cache_hours` | `12` | как часто перечитывать сайт колледжа |
| `college_max_chars` | `15000` | сколько текста с сайта колледжа давать модели |
| `reports_key` | — | ключ для `?health&key=...` с подробностями |

## Сколько стоит

На месяц выделено $2. Каждый день скрипт делит остаток на оставшиеся дни
(1-го числа это примерно $0.066 в день). После ответа он берёт из ответа
DeepSeek количество токенов, считает стоимость и прибавляет к расходу. Когда
дневная часть потрачена, чат до полуночи пишет «Лимит на сегодня исчерпан».
Если DeepSeek ответил ошибкой, вопрос не засчитывается.

Один обычный ответ обходится примерно в $0.001–0.002, «Подумать глубже» в
$0.003–0.006. Большая часть подсказки одинаковая для всех и берётся из кэша
DeepSeek, поэтому почти ничего не стоит. В итоге в месяц выходит около 1200–1800
ответов.

Сколько потрачено сегодня: `.../api/ai-chat.php?health&key=<reports_key>`.

## Защита

Код в `public/api/ai-guard.php`, тесты в `scripts/ai-guard.test.php` и
`src/ai-php.test.js`.

- Сообщения вида «игнорируй инструкции», «ты теперь DAN», поддельные
  «Assistant:», base64 и похожие ловятся по шаблонам. Явная атака до модели не
  доходит и не тратит лимит. Если похоже на атаку, но не точно, модель получает
  дополнительное предупреждение.
- Ответ модели проверяется перед отправкой: нет ли там кусков системной
  подсказки, ключей или путей сервера. Если есть, ответ заменяется отказом.
- Текст с сайта колледжа и объявления передаются модели как данные, а не как
  команды.
- Ответы чата подписываются секретом сервера (`sig`). Если кто-то подделает
  «ответ ассистента» в истории, он просто выкинется.
- Из ответов убираются внешние картинки и ссылки `javascript:`/`data:`.
- Запрос принимается, только если пришёл с нашего сайта (`Origin`/`Referer`,
  заголовок `X-Logos-Client`).
- Картинки проверяются по содержимому, SVG не принимаются.
- 3 атаки за час — блокировка на час, 6 — на сутки. IP берётся из `REMOTE_ADDR`,
  подменить `X-Forwarded-For` не получится.

Это защита от очевидного, а не гарантия. Поэтому в подсказке нет ничего
секретного, ключ есть только в PHP. Если нашли обход, нужно добавить шаблон в
`guard_patterns()` и пример в тест.

Все срабатывания пишутся в журнал ошибок PHP (строки `logos-ai: guard ...`) и
приходят в Telegram (см. `alerts.md`).

## Ошибки

| На странице | Причина |
| --- | --- |
| «ИИ-агент ещё не загружен на этот сервер» | нет `api/ai-chat.php` или хостинг не выполняет PHP |
| «ИИ-агент ещё не настроен на сервере» | не найден конфиг или выключен `curl` |
| «Сервер ИИ отклонил ключ API» | ключ неправильный или удалён |
| «На счёте DeepSeek закончились средства» | пополнить баланс |
| «Слишком много сообщений подряд» | сработал `per_ip_limit` |
| «Вы задали все 15 вопросов на сегодня» | сработал `per_ip_daily` |
| «Лимит ИИ-агента на сегодня исчерпан» | потрачен дневной бюджет |
| Хостинг показывает свою страницу 500 | открыть `.../api/ai-chat.php?selftest`, он покажет, какой шаг не проходит |
| «На сервере не хватает файлов ИИ» | залита не вся папка `api` |
| «Сервер ИИ временно недоступен: ошибка скрипта» | ошибка PHP, обычно старая версия или нет `mbstring` |
| «Сервер ИИ вернул ошибку» / «ИИ не ответил» | сбой у хостинга или DeepSeek, смотреть журнал PHP |
| «Сервер ИИ ответил не в том формате» | вместо JSON пришла страница ошибки хостинга |
| «Запрос не с сайта» / «Запрос с другого сайта» | сайт открыт с другого адреса (добавить в `allowed_hosts`) или это бот |
| «ИИ временно недоступен с вашего устройства» | блокировка после атак |

Хостинг перехватывает ответы с кодом 5xx и показывает свою страницу, поэтому
ошибки сервера чат отдаёт с кодом 200 и полем `error`.

## Запуск у себя

Vite не умеет PHP, поэтому в режиме разработки запросы к `/api` идут на
встроенный сервер PHP:

```bash
npm run build
cp deploy/logos-ai-config.example.php dist/api/ai-config.php   # вписать ключ
php -S localhost:8787 -t dist      # в отдельном терминале
npm run dev
```

## Оформление ответов

Правила лежат в `formatting_rules()` в `ai-chat.php`. Модель первой строкой
пишет предмет (`[[предмет: math]]`), и карточка ответа красится в его цвет.
Формулы пишутся в LaTeX (`$...$`), графики блоком `chart` с JSON. Формулы для
графиков считаются своим парсером, без `eval` (`src/ai-format.js`).

DeepSeek иногда переходит на китайский. Иероглифы вырезаются на сервере
(`strip_cjk`) и в браузере (`cleanReply`), а если их больше 20%, сервер просит
модель переписать ответ. Температура снижена до 0.6, так это случается реже.

## Слабые устройства

На слабых телефонах и компьютерах включается режим «Лёгкий» (`src/perf.js`,
`src/perf.css`): без размытия, теней, бесконечных анимаций и 3D на главной.
Включается сам, если мало памяти или ядер, включена экономия трафика или
страница тормозит в первые 2 секунды. Вручную: `?perf=lite` или `?perf=full`
в адресе.
