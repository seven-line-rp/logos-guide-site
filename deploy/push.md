# Push-уведомления

Уведомления приходят на Android, iPhone (iOS 16.4+, сайт добавлен на экран
«Домой») и компьютер, даже когда сайт закрыт. Включаются на странице
`https://logos-guide.ru/notifications` (колокольчик в шапке, пункт меню «Уведомления»).
Там же можно сразу проверить каждый вид. Старый адрес `/testNotification` ведёт туда же.

Какие бывают:

| Вид | Когда приходит | Откуда |
| --- | --- | --- |
| Начало пары | за 5 минут до звонка | крон, по звонкам из `src/schedule.js` |
| Конец пары | в момент звонка, с переменой или обедом | крон |
| Событие | когда в «Объявлениях» появилось событие или наступило его время «С» | крон |
| Новая версия | после выкладки сборки с новой версией в `package.json` | крон |
| Сообщение | когда его отправили из панели | `/admin/push` |

Расписание студента на сервер не уходит. Сервер присылает «через 5 минут 2-я
пара», а сервис-воркер на телефоне сам подставляет из сохранённого расписания
предмет, кабинет и кнопку «Маршрут».

## Что нужно на хостинге

PHP 7.4+ с расширениями `openssl` и `curl` (на reg.ru они включены). Больше
ничего ставить не нужно: шифрование и подпись сделаны в
`public/api/notify-lib.php` без библиотек.

При первом запросе `api/notify.php` сам создаёт папку `logos-push` на уровень
выше `public_html`:

- `vapid.json` — ключи сервера. **Не удаляйте**: с новыми ключами все
  подписки перестанут работать, и включать уведомления придётся заново;
- `subscriptions.json` — подписки браузеров и выбранные темы;
- `state.json` — что крон уже отправил сегодня.

Если папка не создаётся, проверьте права на запись в домашнюю папку сайта
(то же самое нужно для объявлений, см. `notices.md`).

Если вы выкладывали раньше, старые `api/push.php` и `api/push-lib.php`
можно удалить: файлы переименованы в `notify.php` и `notify-lib.php`, потому
что хостинг отдавал 403 на прежнее имя. Права на новые файлы — 644.

## Панель

`https://logos-guide.ru/admin/push`, ключ тот же, что для объявлений
(`notices_key` в `logos-ai-config.php`). Можно выбрать тему, написать
заголовок (до 60 символов), текст (до 180) и ссылку на страницу сайта. Есть
шаблоны, например «Новая версия сайта». Перед отправкой кнопка просит
подтвердить. Сообщение получат только те, кто выбрал эту тему.

## Крон

Звонки, события и новая версия рассылаются, только если раз в минуту
запускать `notify.php`. В панели reg.ru: «Планировщик заданий (cron)» →
добавить задание с периодом «каждую минуту» и командой

```
/usr/bin/php ~/logos-guide.ru/public_html/api/notify.php cron
```

Путь до `public_html` поправьте под свой. Если запускать PHP из крона нельзя,
подойдёт запрос по адресу (ключ — `push_cron_key` или, если его нет,
`notices_key`):

```
wget -q -O /dev/null "https://logos-guide.ru/api/notify.php?cron=КЛЮЧ"
```

```php
// logos-ai-config.php
return [
    // ...
    'push_cron_key' => 'другая-длинная-строка',   // необязательно
    'push_contact' => 'mailto:почта@команды.ru',  // необязательно, видят Google и Apple
];
```

Если крон опоздал на пару минут, напоминание всё равно уйдёт, но один раз.
При самом первом запуске он только запоминает текущие события и версию и
ничего не рассылает. Проверить, что крон работает, можно в панели: под числом
компьютеров написано «Крон по звонкам работает».

Проверить расписание звонков без ожидания:

```
php public_html/api/notify.php cron $(date -d '2026-10-27 10:35' +%s)
```

## Если уведомления не приходят

- **iPhone:** сайт должен быть открыт с иконки на экране «Домой», не из
  Safari. Включать уведомления нужно оттуда же.
- **Android:** проверьте, что уведомления браузера не выключены в настройках
  телефона, и что для браузера не включена экономия заряда.
- **Компьютер:** уведомления браузера могут быть выключены в Windows
  («Параметры → Система → Уведомления») или в macOS. Ещё мешает режим
  «Не беспокоить».
- «Показать» на странице уведомлений работает, а «С сервера» нет — смотрите
  ответ `api/notify.php` во вкладке «Сеть»: там написано, что не так.
- Подписки, которые браузер отозвал, сервер удаляет сам при следующей отправке.
