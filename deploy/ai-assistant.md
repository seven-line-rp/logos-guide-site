# ИИ-помощник на DeepSeek

В путеводителе есть плавающий чат для компьютеров и ноутбуков (ширина экрана от 1025 px, мышь/тачпад). На телефонах и планшетах виджет скрыт — мобильную версию можно добавить отдельно.

Помощник отвечает по каталогу помещений и возможностям сайта. Он не получает расписание, контакты, стоимость обучения, список преподавателей или актуальные объявления и должен прямо говорить, если данных нет.

## Важно про ключ

Браузер **не обращается к DeepSeek напрямую**. Запрос проходит через сервер `/api/chat`, а `DEEPSEEK_API_KEY` хранится только в серверном окружении. Не добавляйте ключ в React-код, `VITE_*`, публичный репозиторий или клиентский `.env` для сборки. Реальный `.env` уже исключён из Git.

Создать ключ можно в [панели DeepSeek](https://platform.deepseek.com/api_keys). Сам ключ — это способ авторизации, а не бесплатный лимит: API тарифицируется по токенам. Сейчас сервер использует `deepseek-flash`; его цена зависит от времени и попадания входного текста в кэш. По [официальной таблице тарифов](https://api-docs.deepseek.com/quick_start/pricing/), для Flash цена за 1 млн токенов — $0.15 за вход без кэша и $0.60 за выход в непиковое время; в пиковое — $0.30 и $1.20 соответственно. Эти тарифы могут измениться, проверьте актуальную таблицу DeepSeek перед запуском.

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и укажите серверный ключ:

   ```dotenv
   DEEPSEEK_API_KEY=ваш_секретный_ключ
   PORT=3000
   ```

2. Для разработки запустите Vite. Встроенный сервер API читает `.env` и отвечает на `/api/chat`:

   ```bash
   npm ci
   npm run dev
   ```

3. Для проверки production-варианта:

   ```bash
   npm run build
   npm start
   ```

   Откройте адрес, указанный в терминале. `server.mjs` отдаёт сайт из `dist` и обслуживает API на том же origin. На сервере продакшена задайте `DEEPSEEK_API_KEY` как секрет переменной окружения; файл `.env` туда добавлять необязательно.

Если ключ не настроен, интерфейс покажет статус подключения, а API вернёт `503` без обращения к DeepSeek. Переписка хранится только в памяти открытой вкладки и не записывается сайтом в `localStorage` или базу данных; для ответа текущие сообщения диалога передаются DeepSeek.

## Размещение

`npm run preview` и обычная статическая публикация папки `dist` **не запускают серверный API**. Текущий общий хостинг с Apache/nginx, настроенный только на статику (см. [`reg-ru.md`](reg-ru.md)), продолжит отдавать сайт, но `/api/chat` там работать не будет. Для живого ИИ нужен Node.js-хостинг/VPS, запускающий `npm start`, либо отдельный серверless API с совместимым контрактом и проксированием `/api/chat` с того же домена.

Пример обратного прокси nginx для Node-сервера, работающего на том же VPS:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

Если nginx — доверенный прокси и сам перезаписывает `X-Forwarded-For`, задайте серверу `TRUST_PROXY=true`, чтобы лимит запросов применялся к адресу посетителя, а не к адресу nginx. Не включайте этот параметр, если сервер доступен напрямую из интернета: клиент сможет подделывать этот заголовок.

## Ограничения и защита

- Сервер добавляет системные правила и фактический каталог помещений из `src/data.js`; клиент не может подменить системную инструкцию.
- API принимает только недлинную историю пользовательских/ассистентских сообщений, ограничивает размер запроса и делает не более 12 запросов в минуту с одного адреса.
- Ответы запрашиваются без потоковой передачи; запрос к модели ограничен 30 секундами.
- Не передавайте помощнику персональные или чувствительные данные. Для безопасности, расписания и актуальных административных вопросов обращайтесь к сотрудникам колледжа.
