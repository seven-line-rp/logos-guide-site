# Свой голос для промо-ролика

Сюда кладутся записи фраз для ролика из панели (`/admin/promo`). Каждая фраза — отдельный файл.
Формат любой: m4a (диктофон iPhone), mp3, wav, ogg, webm. Номер в начале названия можно не ставить,
главное — слово после него (`hook`, `brand`…), по нему скрипт понимает, что это за фраза.

## Как записать

- Тихая комната, телефон в 20–30 см от рта, чуть сбоку (чтобы не «дуло» в микрофон).
- Обычный диктофон телефона подходит. Перед фразой и после — секунда тишины, её обрежет скрипт.
- Читайте живо, как объясняете другу, без спешки. Если ошиблись — перезапишите фразу целиком.
- Одна запись — одна фраза. Если записали всё одним файлом, порежьте на фразы в любом редакторе.

## Как собрать ролик с вашим голосом

1. Положите файлы в эту папку (`promo-voice/`).
2. Соберите озвучку, музыку и видео (нужны python3, numpy, ffmpeg, node, Playwright):

   ```bash
   python3 scripts/build-promo-voice.py --from-dir promo-voice
   python3 scripts/build-promo-music.py
   npm run dev
   node scripts/render-promo.mjs
   ```

   Анимация подстроится под ваш темп: тайминги фраз пересчитываются из записей.
3. Проверьте ролик во вкладке «Промо-ролик» и закоммитьте `public/promo/`, `src/admin/promo-timeline.json` и эту папку.

Если не хочется ставить программы, запишите голос прямо во вкладке «Промо-ролик»
панели: там каждая фраза записывается с микрофона кнопкой, и готовый ролик
скачивается из браузера. Или пришлите файлы тому, кто соберёт ролик, или Claude.

Подробнее — `docs/promo.md`.
